# Security Policy

## Supported Versions

Security fixes go into the latest release. Please update to it before reporting.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

## Reporting a Vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the Security tab of this repository and choose "Report a vulnerability".

Include the plugin version, the WordPress and WooCommerce versions, and the steps to reproduce it.

I aim to reply within 7 days. If the report is confirmed, I will fix it in a new release and credit you in the release notes unless you ask me not to. If I decline it, I will tell you why.
